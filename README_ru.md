```text
╭─ kapsel [pwsh] ~/Projects/Kapsel 14:32:05
╰─ ❯ git checkout -b feature/dynamic-specs
✔ 0  git checkout -b feature/dynamic-specs  ⏱ 24ms
```

> **Скрывайте сложность, открывайте простоту.**
> Запускайте свои нативные исполняемые файлы оболочки как обычно, наслаждаясь автоматическим переводом команд, встроенными подсказками, расширенными спецификациями завершения и модульным инструментарием — всё в песочнице `~/.kapsel/`.

## 💡 Зачем нужен Kapsel?

Переключение между операционными системами часто приводит к нарушению мышечной памяти, захламлённым dotfiles и разрозненным настройкам автодополнения. Kapsel устраняет этот разрыв с помощью неинвазивного капсульного слоя:

| Проблема | Традиционная настройка оболочки | С Kapsel |
| :--- | :--- | :--- |
| **Сложности кросс-платформенности** | Разрозненные команды в разных ОС (`dir` против `ls`, `rmdir` против `rm -rf`) | Единый слой команд в стиле Linux для Windows, macOS и Linux |
| **Загрязнение профиля оболочки** | Раздутый `.bashrc` или `$PROFILE` с хрупкими глобальными скриптами | 100% автономная песочница в `~/.kapsel/` (ноль глобальных изменений) |
| **Настройка автодополнения** | Ручная настройка для каждой оболочки, часто неполная или медленная | Мгновенные контекстно-зависимые дополнения для более чем 1000 CLI-инструментов через Carapace |
| **Разрозненность инструментов и синхронизации** | Разрозненные инструменты, требующие повторяющейся ручной установки | Интегрированные плагины `kps` для сред выполнения, зеркал, быстрого перехода по каталогам и синхронизации |

## ✨ Возможности

- **🌐 Единообразие команд на всех платформах**: Вводите стандартные команды (`ls -la`, `cat`, `rm -rf`, `grep`) естественно в любом терминале — они автоматически переводятся в нативные примитивы хост-системы, не затрагивая встроенные функции хоста.
- **⚡ Контекстно-зависимые автодополнения**: Интеграция с [Carapace](https://carapace.sh) обеспечивает многоуровневые дополнения аргументов и контекста (ветки Git, образы Docker, npm-скрипты) в PowerShell, Bash и Zsh.
- **🛡️ Изолированная песочница без следов**: Всё (бинарные файлы, история SQLite, декларативные спецификации, плагины и журналы) хранится внутри `~/.kapsel/`. Ваши конфигурационные файлы хост-оболочки остаются полностью нетронутыми.
- **🧩 Курируемая экосистема плагинов**: Доступ к мощным утилитам для разработчиков (`zoxide`, `mise`, `chsrc`, `pueue`, ИИ-ассистенты) напрямую через единую команду `kps`.
- **🎨 Современная эстетика карточек**: Чистое визуальное оформление команд в виде карточек с бейджами кода выхода (`✔ 0` / `✘ 1`), секундомером времени выполнения и встроенной поддержкой интернационализации на 7 языках.

## 🚀 Быстрый старт

Запустите интерактивную оболочку-капсулу:

```bash
kapsel
```

Внутри Kapsel команды выполняются нативно с улучшенной обратной связью:

```bash
# 1. Нативный пропуск команд с таймингом и карточкой кода выхода
git status
docker ps

# 2. Универсальный перевод команд на любой ОС
rm -rf ./temp_dir
cat package.json

# 3. Используйте встроенные плагины в любое время
kps portal work        # Переход в директорию (zoxide)
kps ai "объясни git rebase"  # Спросите терминального ИИ-ассистента
kps shore get          # Автоматический выбор самых быстрых зеркал пакетов

# 4. Проверьте состояние капсулы
kps status
```

> **Одноразовое выполнение**: Вы также можете вызывать инструменты Kapsel напрямую из вашей обычной оболочки с помощью `kps <команда>` (например, `kps portal`, `kps status`, `kps ai`).

## 🧩 Встроенные плагины

Kapsel поставляется с предварительно настроенными 11 независимыми официальными плагинами в пространстве имен `kps`:

| Плагин | Команда | Что делает | На базе |
| :--- | :--- | :--- | :--- |
| **`portal`** | `kps portal` / `z` | Быстрый переход по директориям с frecency-взвешиванием | [zoxide](https://github.com/ajeetdsouza/zoxide) |
| **`ai`** | `kps ai` | Терминальный ИИ-помощник для генерации и объяснения команд | OpenAI / Claude / Ollama |
| **`init`** | `kps init` | Менеджер многоплатформенных сред выполнения (Node, Python, Go, Rust) | [mise](https://github.com/jdx/mise) |
| **`shore`** | `kps shore` | Бенчмарк и переключение на самые быстрые зеркала пакетов и ОС | [chsrc](https://github.com/AkihiroSuda/chsrc) |
| **`install`** | `kps install` | Универсальный установщик ПО, объединяющий 20+ менеджеров пакетов | [mpm](https://github.com/MrEiu/mpm) |
| **`alias`** | `kps alias` | Кросс-платформенный перевод алиасов без коллизий пространств имен | Собственный движок |
| **`autopilot`**| `kps autopilot`| Фоновая очередь и автономный демон-исполнитель задач | [pueue](https://github.com/Nukesor/pueue) |
| **`help`** | `kps help <cmd>`| Мгновенные, создаваемые сообществом практические шпаргалки по командам | [tealdeer](https://github.com/dbrgn/tealdeer) |
| **`fuck`** | `kps fuck` | Интеллектуальная автокоррекция и исправление синтаксиса ошибочных команд | [thefuck](https://github.com/nvbn/thefuck) |
| **`profile`** | `kps profile` | Кросс-платформенная синхронизация dotfile-файлов и конфигурации рабочей станции | [chezmoi](https://github.com/twpayne/chezmoi) |
| **`rec`** | `kps rec` | Интерактивное сохранение и запуск сниппетов CLI-команд | [pet](https://github.com/knqyf263/pet) |

## 📦 Установка

### Рекомендуемый способ (pipx / pip)

```bash
# Изолированная установка через pipx (рекомендуется)
pipx install kapsel-cli

# Или стандартная установка через pip
pip install --upgrade kapsel-cli
```

### Автоматические установщики одной командой

Быстрые скрипты начальной настройки, которые автоматически определяют вашу ОС и настраивают автодополнение:

```bash
# macOS и Linux:
curl -fsSL https://raw.githubusercontent.com/MrEiu/Kapsel/master/scripts/install.sh | bash

# Windows (PowerShell):
irm https://raw.githubusercontent.com/MrEiu/Kapsel/master/scripts/install.ps1 | iex
```

### Другие варианты установки

- **Автономные предварительно скомпилированные бинарные файлы**: Загрузите готовые к запуску релизы с [GitHub Releases](https://github.com/MrEiu/Kapsel/releases/latest).
- **Менеджеры пакетов**: Доступен в Scoop (`scoop install kapsel`), Homebrew и Debian/Ubuntu `.deb`.
- **Сборка из исходного кода**: `git clone https://github.com/MrEiu/Kapsel.git && cd Kapsel && pip install -e .`

👉 *Для получения информации о зеркалах в Китае и подробностях установки через менеджеры пакетов для всех платформ, см. **[docs/INSTALLATION.md](docs/INSTALLATION.md)**.*

## ⚙️ Конфигурация

Kapsel хранит свою конфигурацию в `~/.kapsel/config.yaml`. Управляйте настройками прямо из терминала:

```bash
# Просмотр панели конфигурации
kps config

# Открыть файл конфигурации во внешнем редакторе
kps config edit

# Настройка параметров на лету
kps config set ui.enable_banner false
kps config set interaction.autosuggest_sensitivity 0.2
```

## 🏛️ Архитектура и песочница

Kapsel следует **Принципу нулевого загрязнения**. Все состояние выполнения строго изолировано:

```text
~/.kapsel/
├── config.yaml          # Общесистемная конфигурация интерфейса, темы и настройки взаимодействия
├── history.db           # Постоянная база данных SQLite для хранения истории команд и статистики
├── bin/                 # Автономные бинарные инструменты пользовательского пространства (carapace, zoxide, mise...)
├── specs/               # Декларативные YAML-спецификации автодополнения
├── plugins/             # Установленные официальные и сторонние расширения плагинов
└── logs/                # Диагностические журналы и метрики сессий
```

- **Двухрежимный движок**: Нативные исполняемые файлы запускаются напрямую через передачу в дочернюю оболочку хоста; утилиты капсулы запускаются через единый реестр `kps`.
- **Сторожевой механизм коллизий**: Гарантирует, что встроенные команды нативной оболочки (например, `Get-Alias`, `Get-Help` в PowerShell) никогда не перехватываются и не захватываются.
- **Изолированные плагины**: Плагины работают независимо, гарантируя, что сторонние расширения не могут привести к сбою основной оболочки.
